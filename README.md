# Vinit Vekaria — portfolio

A static Next.js portfolio for Vinit's software development work and Canadian ventures.

## Run locally

```bash
cd project
npm ci
npm run dev
```

## Verify and export

```bash
cd project
npm run typecheck
npm run build
```

The static site is written to `project/out/`. The page uses authentic HomHunt app imagery and ASAP Booth brand art. The warehouse interface is explicitly illustrative; it does not expose client software. The résumé download is `project/public/VinitVekaria.pdf`.

The current page lives in `project/app/`. Earlier starter components remain in the repository for historical reference and are excluded from TypeScript compilation.
